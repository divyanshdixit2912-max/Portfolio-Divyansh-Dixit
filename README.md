# Premium Portfolio Starter (Next.js + TypeScript + Tailwind + Framer Motion)

Quick start:
1. npm install
2. npm run dev
3. Edit `data/portfolioData.ts` to change all content across the site.

Project structure:
- app/ - Next.js app router pages and route handlers
- components/ - reusable UI components (Navbar, Hero, Footer)
- sections/ - page sections (About, Projects, etc.)
- data/ - the single source of truth: portfolioData.ts
- styles/ - global styles + Tailwind
- types/ - TypeScript types for the data

Important: Do not hardcode personal info elsewhere. Change everything via `data/portfolioData.ts`.
